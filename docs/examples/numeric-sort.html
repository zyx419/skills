BUG / DEMO

Numeric sorting puts 10 before 2

JAVASCRIPT · ARRAY SORT
REPRODUCIBLE EXAMPLE

1SymptomA

EXPECTED · NUMERIC ORDER
[2, 10, 30]
ACTUAL · DEFAULT SORT
[10, 2, 30]
ACTUAL
ORDER →
10
2
30

2Root causeB

[2, 10, 30].sort(/* no comparator */)

Default sorting compares string values. "10" comes before "2" because "1" comes before "2".

3Fix

const values = [2, 10, 30];
- values.sort();
+ values.sort((a, b) => a - b);

A numeric comparator orders values by their difference.

4Before / after outputC

BEFORE · JSON OUTPUT
[10,2,30]
